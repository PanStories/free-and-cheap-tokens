## OD-01 · FTC 2026 年 Endorsement Guides 修订的具体条款未获一手来源印证

| 字段 | 内容 |
|---|---|
| **ID** | OD-01 |
| **Slug** | `waiting-on-external-condition` |
| **类别** | 合规（美国） |
| **Status** | **RESOLVED 2026-09-28** |
|---|---|
| **Resolution** | 用户撤回联盟返佣变现路线，改走 **OSS + Hosted Convenience**（MCP 源码 MIT 免费，托管便利层付费）。`disclosure` 对象在 Schema 中可选化保留（不再 required），前端永远不设 `affiliate=true`。FTC 16 CFR Part 255、《互联网广告管理办法》第九/十八条、《广告法》绝对化用语这一组合规面**整体不适用**。原"按更严标准设计"的临时处置随 OD-01 同步废弃 |
| **优先级** | 中（不阻塞 MVP） |
| **关联** | PRD 8.4、PRD 13.1 D3、AC-12.1 / AC-12.2 / AC-12.5 |

### 已确认为真的部分（有一手来源，可直接作为依据）

FTC Endorsement Guides（16 CFR Part 255）的下列要求**已有多方一手/权威来源确认，不受本条未决状态影响**：

- 存在「material connection」（佣金、免费产品、亲属/雇佣/股权关系等）即须披露
- 披露必须 **clear and conspicuous**：贴近其所适用的推荐主张、不得埋在页脚/折叠区/长串 hashtag 内、移动端同样可见
- 语言须为大白话；仅写「This page contains affiliate links」**不合格**（未说明报酬关系）
- **品牌方与推广方承担连带责任**——不能把合规义务全推给分享者，必须在产品内默认带出披露
- 2026 年每次违规民事罚款上限约 **$53,088**，且每条不合规内容可单独计罚

### 未确认为真的部分（本条未决的核心）

有**二手 SEO 型站点**声称 2026 年 3 月有一轮修订，涉及：

1. 「affiliate」一词对一般消费者不够清晰，大众向内容须改用报酬关系的白话表述
2. AI 生成内容需**单独**披露（不与联盟报酬披露互相替代，两者都要出现）
3. 视频/播客内容须在**前 30 秒内**含口播披露
4. 存在某个 **9 月 1 日**的合规节点

**处置：以上四点均未获一手来源交叉印证，不作为 MVP 硬约束。**

### 临时处置（Blocked By 解除前）

按**更严标准**设计并落地，即无论 2026 修订是否真实存在，我们均已满足：

- 披露使用大白话报酬关系表述，而非仅用「affiliate」一词 → 覆盖第 1 点
- AI 生成内容可识别（`verified_by=agent` 的条目显式标注）→ 覆盖第 2 点
- 分享卡片与可复制文案**各自内嵌**披露，不依赖任何时序性呈现 → 覆盖第 3 点的精神（我们的传播载体是静态图文，非音视频）
- 披露在上线首日即默认带出，不设过渡期 → 覆盖第 4 点的时间压力

### 关闭条件

取得以下任一：(1) FTC 官方 Federal Register / 官方指南页面原文；(2) 执业律师书面意见。关闭时在下方「关闭记录」写明来源与日期。

|---|---|

| **Status** | **RESOLVED 2026-09-28** |
|---|---|
| **Resolution** | 联盟返佣路线整体撤回，阿里云联盟复核不适用。阿里云百炼免费额度照常收录（事实型信息），`claim_url` 走官方直链 |
| **优先级** | 中（不阻塞 MVP；已按 D 类处理） |
| **关联** | PRD 8.1、PRD 8.3、PRD 13.1 D2 |

### 背景与裁定

我检索到阿里云「邀客得好礼」类邀新活动的**实例活动期为 2026-02-14 至 2026-03-31**，最高返 3000 元优惠券、邀请次数上限 100 次。当前日期 **2026-09-28**，该活动已过期约 6 个月——**这是一条死链**。

**总监裁定（2026-09-28）：阿里云从 A 类剔除，改按 D 类处理。** 这是一次典型的「数据保鲜」自证：我们自己产品的核心主张就是竞品列表里有死链，如果自己的联盟清单里就躺着一条死链，可信度叙事会当场崩塌。

### 待核实

- 阿里云当前是否有在架的邀新/返佣活动？活动期是什么？
- 若有，个人创作者是否可参与（是否需要企业实名 / 是否需要阿里云官网实名认证）？
- 阿里云分销伙伴体系是否有面向个人/小微主体的档位？（调研时**未检索到**公开的个人档位）

### 临时处置

```

affiliate_url: null
affiliate_policy_status: unverified

```
